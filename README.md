# 陈照敬的生日星光

移动端优先的生日祝福网页，使用 Vue 3、Vite、Three.js、GSAP 和 canvas-confetti。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：`npm run build`，输出在 `dist/`。

## 自定义

- 本次祝福对象为陈照敬，生日为 1月10日。在 `src/App.vue` 修改 `birthdayName`、`birthdayDate`、各场景标题及结尾署名；贺卡正文位于 `src/components/GiftLetter.vue`。
- 时光胶片使用 `public/time1.webp` 到 `time14.webp`，按数字 1→14 播放。图片保留方向与宽高比，最长边不超过 1920px；横图和竖图均完整显示，照片备注使用更大的浅金文字和深色衬底。原始 JPG 备份在 `assets/originals/time-photos/`，不随站点发布。
- 月亮彩蛋相册使用 `public/pic1.webp`、`pic2.webp`、`pic3.webp`；拼图仍使用 `pic2.webp`。
- 在 `src/memories.js` 的 `memories` 数组里修改时光胶片的顺序及每帧 `caption` 备注；每张照片的文案均位于对应条目的 `caption`，可继续逐张调整。月亮彩蛋相册使用同文件中的 `albumPhotos`。
- 照片使用 WebP 格式，建议每张小于 200KB。月亮相册支持左右滑动、点按照片和左右箭头翻页。
- 访问 `/?secret=love` 查看隐藏页面。
- 点击打开信封后播放 5 秒的星轨穿梭（细碎星光与柔和光流），穿梭结束后遮罩柔和淡出，回忆胶片才开始放映：默认缓慢移动，每张居中停留约 3.4 秒并显示备注。支持鼠标、手指拖动、方向键和暂停；最后一张停留结束后，全部照片会展开成上、中、下三层立体漩涡：上层宽、下层窄，在不同高度绕行，保持照片朝向视线，依次下沉、缩小并消失，约 3.6 秒后柔和进入礼盒。漩涡期间锁定翻页与拖拽，页面切到后台或打开月亮相册时暂停收尾。启用系统“减少动态效果”时改为手动翻看及继续，并使用短淡出代替旋转。左上角月亮连点 5 次仍可查看隐藏相册。
- 信件依次通过三层互动打开：第一层按住盒盖向上滑，第二层按住丝带向下滑，第三层点击碎纸。前两层拉到提示松手时释放才解锁，方向错误或距离不足会回弹；支持手指、鼠标，也支持键盘方向键与回车。拖动有跟随光迹和星屑，解锁时散出一簇光点，每层有不同的轻音效；随后露出带细噪点纸纹和弯曲阴影的贺卡。信内恢复原来的逐字打字机效果，约每 42 毫秒出现一个字，结束后光标消失；正文没有模糊、渐显或位移动画。背景光斑、气球和贺卡提供弱视差；金箔的下落时间、旋转和横向漂移均有随机变化。
- 祝福信之后是可选的 9 块照片拼图。轻点两块碎片交换位置；拼好后会出现带心电图光线的跳动红心，持续 5 秒，再进入蛋糕。点「下一步」或上滑可跳过，不出现爱心。从蛋糕返回拼图时会重新打乱。
- 吹灭蜡烛后，先让白烟向上飘散，再出现礼花和夜空烟花。烟花结束停留在星空中，只有三颗稍大的星星可以点击；每次只显示一句心里话。三颗全部点亮并读完后，才解锁“生日快乐🎂祝你永远18岁”的完整祝福。
- 最后可以输入一句心愿，回车或点击箭头让它成为缓缓上浮的气泡，在顶部散成细碎光点。心愿只保存在当前组件内存，不发送请求，不写入浏览器存储；刷新或重播即消失。
- 蛋糕页麦克风按钮前的光圈有柔和呼吸效果，正在听取吹气时节奏稍快，蜡烛熄灭后停止。
- 在最后一页的心愿框输入“杨炼”并回车（或点箭头）可触发隐藏彩蛋：小鸟衔着信封飞近，停住后可以点开信封。信件内容暂留占位，之后在 `src/secretLetter.js` 的 `content` 填写正文；`keyword` 和 `title` 也在同一文件。彩蛋可关闭并再次触发，其他心愿仍正常升空。
- 结尾可以点「从头再看一遍」回到封面，蜡烛和拼图会重置。月亮彩蛋在顶栏留有一句轻提示。

背景音乐为 Web Audio 演奏的《生日快乐》八音盒旋律，只有点击信封后才开始播放，页面隐藏时暂停；不请求外部音频文件。陀螺仪视差在设备支持且授权时启用；麦克风吹气需要 HTTPS 和用户主动授权，长按按钮始终可用。

验证：`node --test test/*.test.js` 检查拼图、音乐、星星解锁、胶片自动推进/拖动/暂停、三层礼盒、心愿气泡的生命周期和小鸟来信彩蛋；`npm run build` 生成生产版本。明暗氛围切换按本次要求暂不加入。
