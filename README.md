# xxx的生日星光

移动端优先的生日祝福网页，使用 Vue 3、Vite、Three.js、GSAP 和 canvas-confetti。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：`npm run build`，输出在 `dist/`。

## 自定义

- 本次祝福对象为xxx，生日为 1月10日。在 `src/App.vue` 修改 `birthdayName`、`birthdayDate`、各场景标题及结尾署名；贺卡正文位于 `src/components/GiftLetter.vue`。
- 时光胶片的源图使用 `public/time1.webp` 到 `time14.webp`，按数字 1→14 播放。开发和构建时会自动生成 `public/memories/time1.webp` 到 `time14.webp`，供胶片展示：保留方向与宽高比，最长边 960px，14 张合计约 880 KiB。生成目录不提交 Git，替换源图后运行 `npm run photos:prepare` 可单独刷新。横图和竖图均完整显示，照片备注使用更大的浅金文字和深色衬底。原始 JPG 备份在 `assets/originals/time-photos/`，不随站点发布。
- 月亮彩蛋相册使用 `public/pic1.webp`、`pic2.webp`、`pic3.webp`；拼图仍使用 `pic2.webp`。
- 在 `src/memories.js` 的 `memories` 数组里修改时光胶片的顺序及每帧 `caption` 备注；每张照片的文案均位于对应条目的 `caption`，可继续逐张调整。月亮彩蛋相册使用同文件中的 `albumPhotos`。
- 照片使用 WebP 格式，建议每张小于 200KB。月亮相册支持左右滑动、点按照片和左右箭头翻页。
- 封面出现后就会预加载胶片照片，优先前两张，复用相同图片地址的缓存；图片节点仍在穿梭结束后才挂载。胶片不使用浏览器懒加载，自动放映会等当前照片解码完成才开始计时，也会等下一张准备好才移动。慢网时显示加载提示，失败时可以点击「重新加载」，也可以手动翻看其他照片。
- 访问 `/?secret=love` 查看隐藏页面。
- 点击打开信封后播放 5 秒的星轨穿梭（细碎星光与柔和光流），穿梭结束后遮罩柔和淡出，回忆胶片才开始放映：默认缓慢移动，每张居中停留约 3.4 秒并显示备注。支持鼠标、手指拖动、方向键和暂停；最后一张停留结束后，照片和文字会柔和淡出，中央的暖金色细光线收拢成一点星光，整个过渡持续 2 秒，再进入礼盒。过渡不再旋转、复制照片或创建额外画布，只对少量装饰元素做透明度和缩放动画；期间暂停背景星空、环境光斑与视差，锁定翻页和拖拽，页面切到后台或打开月亮相册时暂停收尾。启用系统“减少动态效果”时改为手动翻看及继续，并使用约 0.32 秒的短淡出。左上角月亮连点 5 次仍可查看隐藏相册。
- 信件依次通过三层互动打开：第一层按住盒盖向上滑，第二层按住丝带向下滑，第三层点击碎纸。前两层拉到提示松手时释放才解锁，方向错误或距离不足会回弹；支持手指、鼠标，也支持键盘方向键与回车。拖动有跟随光迹和星屑，解锁时散出一簇光点，每层有不同的轻音效；随后露出带细噪点纸纹和弯曲阴影的贺卡。信内恢复原来的逐字打字机效果，约每 42 毫秒出现一个字，结束后光标消失；正文没有模糊、渐显或位移动画。背景光斑、气球和贺卡提供弱视差；金箔的下落时间、旋转和横向漂移均有随机变化。
- 写给xxx的贺卡落款下方提供「听听小新的祝福」按钮，点击播放 `public/蜡笔小新.m4a`（约 15 秒），附带时间、进度和停止操作，不自动播放或提前下载。播放前先暂停背景音乐，播放完毕、手动停止、加载失败或离开信件时释放暂停；背景音乐只在原本开启且页面可见时恢复。切到后台会停止语音，回到页面时恢复原有背景音乐设置；语音播放期间点击顶栏音乐按钮也不会造成两段音频重叠。
- 祝福信之后是可选的 9 块照片拼图。轻点两块碎片交换位置；拼好后会出现带心电图光线的跳动红心，持续 5 秒，再进入蛋糕。点「下一步」或上滑可跳过，不出现爱心。从蛋糕返回拼图时会重新打乱。
- 吹灭蜡烛后，先让白烟向上飘散，再出现礼花和夜空烟花。烟花结束停留在星空中，只有三颗稍大的星星可以点击；每次只显示一句心里话。三颗全部点亮并读完后，才解锁“生日快乐🎂祝你永远18岁”的完整祝福。
- 最后可以输入一句心愿，回车或点击箭头让它成为缓缓上浮的气泡，在顶部散成细碎光点。最近一条心愿会在当前页面内存中保留，供生日纪念票预填；不发送请求，不写入浏览器存储，刷新或重播即消失。
- 结尾的「制作生日纪念票」入口会打开独立页面，使用陈照敬、1月10日和 `public/time1.webp`，可输入或修改生日心愿（最多 80 字、4 行）。实时预览采用自包含 SVG，生成后导出 900×1560 的 PNG，提供下载按钮、手机长按图片保存，以及设备支持时的系统保存/分享入口。修改心愿后需要重新生成，照片或生成失败时可重试。顶部浅金色「返回生日页面」按钮随页面正常滚动，返回后再次进入会保留本次填写的心愿；从头重播会清空。
- 蛋糕页麦克风按钮前的光圈有柔和呼吸效果，正在听取吹气时节奏稍快，蜡烛熄灭后停止。
- 在最后一页的心愿框输入“杨炼”并回车（或点箭头）可触发隐藏彩蛋：小鸟衔着信封飞近，停住后可以点开信封。信件内容暂留占位，之后在 `src/secretLetter.js` 的 `content` 填写正文；`keyword` 和 `title` 也在同一文件。彩蛋可关闭并再次触发，其他心愿仍正常升空。
- 结尾可以点「从头再看一遍」回到封面，蜡烛和拼图会重置。月亮彩蛋在顶栏留有一句轻提示。

背景音乐为 Web Audio 演奏的《生日快乐》八音盒旋律，只有点击信封后才开始播放，页面隐藏时暂停；不请求外部音频文件。陀螺仪视差在设备支持且授权时启用；麦克风吹气需要 HTTPS 和用户主动授权，长按按钮始终可用。
