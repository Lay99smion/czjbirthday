# 给你的生日星光

移动端优先的生日祝福网页，使用 Vue 3、Vite、Three.js、GSAP 和 canvas-confetti。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：`npm run build`，输出在 `dist/`。

## 自定义

- 在 `src/App.vue` 修改 `letter` 祝福信文案、各场景标题，以及结尾署名。
- 在 `src/App.vue` 的 `photos` 数组里增减照片及其说明文字。将照片放进 `public/`，按数组里的 `src` 填写路径。当前 3 张是可替换的示意照片。
- 照片建议保留 3:4 竖幅、WebP 格式，每张小于 200KB。相册支持左右滑动、点按照片和左右箭头翻页。
- 访问 `/?secret=love` 查看隐藏页面。
- 主场景左上角月亮连点 5 次可查看隐藏相册；点按「开启小宇宙」会出现持续 5 秒的全屏时空穿梭效果。

音乐由 Web Audio 在用户点击信封后生成，不请求外部音频文件。陀螺仪视差在设备支持且授权时启用；麦克风吹气需要 HTTPS 和用户主动授权，长按按钮始终可用。
