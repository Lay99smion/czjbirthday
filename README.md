# 陈照敬的生日星光

移动端优先的生日祝福网页，使用 Vue 3、Vite、Three.js、GSAP 和 canvas-confetti。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：`npm run build`，输出在 `dist/`。

## 自定义

- 本次祝福对象为陈照敬，生日为 1月10日。在 `src/App.vue` 修改 `birthdayName`、`birthdayDate`、`letter` 祝福信文案、各场景标题，以及结尾署名。
- 相册使用 `public/pic1.webp`、`pic2.webp`、`pic3.webp`，由提供的三张同名 JPG 压缩而来；拼图使用第二张。原始 JPG 保留在本地 `assets/originals/`，不随站点发布。
- 在 `src/App.vue` 的 `photos` 数组里增减照片及其说明文字。将照片放进 `public/`，按数组里的 `src` 填写路径。
- 照片建议保留 3:4 竖幅、WebP 格式，每张小于 200KB。相册支持左右滑动、点按照片和左右箭头翻页。
- 访问 `/?secret=love` 查看隐藏页面。
- 点击打开信封后会自动播放持续 5 秒的全屏时空穿梭效果，再进入生日祝福主场景。主场景左上角月亮连点 5 次可查看隐藏相册。
- 祝福信之后是可选的 9 块照片拼图。轻点两块碎片交换位置；拼好后会出现带心电图光线的跳动红心，持续 5 秒，再进入蛋糕。点「下一步」或上滑可跳过，不出现爱心。从蛋糕返回拼图时会重新打乱。
- 吹灭蜡烛先出现礼花，礼花结束后进入独立的夜空烟花过场，最后显示结尾祝福。
- 结尾可以点「从头再看一遍」回到封面，蜡烛和拼图会重置。月亮彩蛋在顶栏留有一句轻提示。

背景音乐为 Web Audio 演奏的《生日快乐》八音盒旋律，只有点击信封后才开始播放，页面隐藏时暂停；不请求外部音频文件。陀螺仪视差在设备支持且授权时启用；麦克风吹气需要 HTTPS 和用户主动授权，长按按钮始终可用。
